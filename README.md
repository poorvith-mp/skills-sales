## Install

Install the entire collection via `npx skills`:
```bash
npx skills add poorvith-mp/skills-sales-support
```

Or install individual skills directly:
```bash
npx skills add poorvith-mp/skills-sales-support --skill <skill-id>
```

For Claude Code plugin marketplace:
```bash
/plugin install poorvith-mp/sales-support
```
