# skills-sales

Sales & Support skills collection for Claude Code, Cursor, Codex, Gemini CLI, and `npx skills` — part of [Skillary](https://github.com/poorvith-mp/skillary) by [Poorvith M P](https://github.com/poorvith-mp).

- **Version**: `v4.0.0`
- **Total Skills**: `14`
- **License**: MIT
- **Hub Repository**: [poorvith-mp/skillary](https://github.com/poorvith-mp/skillary)

## Install

Install the entire collection via `npx skills`:
```bash
npx skills add poorvith-mp/skills-sales
```

Or install individual skills directly:
```bash
npx skills add poorvith-mp/skills-sales --skill <skill-id>
```

## Skills in this Collection

### Pipeline

| Skill ID | Title | Description |
|:---------|:------|:------------|
| `cold-outreach` | [Cold Outreach](skills/cold-outreach/SKILL.md) | Write cold email and DM sequences that get replies, including domain warmup and deliverability. |
| `discovery` | [Discovery](skills/discovery/SKILL.md) | Structure the discovery call: question design, current-state mapping, gap quantification and a close that earns the next meeting. |
| `pipeline-health` | [Pipeline Health](skills/pipeline-health/SKILL.md) | Diagnose deal velocity, stage conversion, forecast accuracy and CRM hygiene. |
| `proposals` | [Proposals](skills/proposals/SKILL.md) | Turn an RFP or opportunity into a win narrative with scope, pricing, timeline, win themes and proof. |
